The generated full knowledge index normalizes authored research types
(`technical-brief` to `brief`, `landscape` to `campaign`) without distinguishing
the source value from the normalized taxonomy. Later, decide whether to preserve
the source type or expose both fields so exact-type consumers can tell which
value was authored. This is non-blocking semantic index hygiene recorded by the
2026-08-16 doc review.
