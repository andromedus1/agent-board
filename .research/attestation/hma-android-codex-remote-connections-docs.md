## Summary

Official OpenAI Remote connections page for Codex, current version: the ChatGPT mobile app on iOS or Android controlling a ChatGPT desktop-app host on macOS or Windows, plus SSH hosts for remote projects.

## Key passages

- [1] "Remote access supports hosts running the ChatGPT desktop app on macOS and Windows. You can control a host from ChatGPT on iOS or Android." "Availability can vary by rollout."
- [2] Host requirements: the ChatGPT desktop app "running on a host that's awake, online, and signed in to the same account and workspace. Mobile setup starts from the app; you can't set it up from the Codex CLI or IDE extension."
- [3] What you can do remotely: send follow-up instructions, "Approve commands and other actions", review outputs and diffs, and "Get notified when ChatGPT completes a task or needs your attention."
- [4] "If that computer sleeps, loses network access, or closes the app, remote access stops until it's available again."
- [5] Troubleshooting includes "The approval request doesn't appear"; workspace admins may need to enable Remote Control access.

## Structural notes

- Official documentation. Sessions in the Codex CLI inside a Herdr pane are not described as reachable; the page says setup cannot be done from the Codex CLI.
