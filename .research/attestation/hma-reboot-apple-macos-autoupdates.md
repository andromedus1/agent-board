## Summary

Apple Mac User Guide page "Keep your Mac up to date" (page served 2026-11-10 with a version selector offering macOS 27 and macOS Tahoe 26; the /26/ URL variant returned the same text). Lists the three Automatic Updates toggles.

## Key passages

- [1] "Click next to Automatic Updates, then do any of the following: To have your Mac download updates without asking, turn on “Download new updates when available.” To have your Mac install macOS updates automatically, turn on “Install macOS updates.” To have your Mac install system files and Rapid Security Responses automatically, turn on “Install Security Responses and system files.”"
- [2] Path: System Settings > General > Software Update > the info button next to Automatic Updates.
- [3] "If you receive a notification that software updates are available, you can choose to install the updates immediately, or choose to install the updates later that night."
