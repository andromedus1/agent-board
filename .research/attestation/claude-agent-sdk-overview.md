# Claude Agent SDK overview

## Summary

Anthropic documents an authentication constraint that makes the SDK a materially
different product path for a third-party terminal companion.

## Key passages

1. The SDK quickstart uses API-key authentication. (Section “Get started”.)
2. Unless Anthropic has approved it, a third-party product may not offer
   claude.ai login or rate limits and should use API-key authentication instead.
   (Section “Get started”.)
