# Codirigent README

## Summary

Codirigent is a multi-session terminal workspace whose visible statuses distinguish a stopped-but-unread response from ordinary idle state. It also documents authoritative hooks with a less-precise detection fallback.

## Key passages

1. Its displayed states are Idle (shell idle), Working (agent generating), Attention (waiting for input or permission), and Ready (agent finished and its response is waiting in an unfocused session). (Section “Features”; lines 190–200.)
2. Real-time status uses hooks when available and falls back to a reader/detector path that the project describes as less precise. (Section “Hook Setup”; lines 231–242.)
3. The workspace keeps multiple agents and projects in one view, persists layouts and sessions, synchronizes the file tree to focus, and supports worktrees and session resume. (Sections “Features”; lines 188–217.)
