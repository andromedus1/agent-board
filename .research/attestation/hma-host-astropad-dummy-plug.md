## Summary

Vendor blog post (Astropad, which sells a remote-desktop product) on whether a headless Mac mini needs an HDMI dummy plug. Vendor-interested practitioner source.

## Key passages

- [1] "M1, M2, M3, M4: all of them create a virtual display on their own. The hardware handles it, nothing extra required."
- [2] "When your Mac mini creates a virtual display with no monitor attached, it defaults to 1920x1080. That's non-Retina resolution."
- [3] "If you're using VNC or Apple Screen Sharing, those tools don't include built-in virtual display support. In that case you'd need a third-party utility or, yes, a dummy plug."
