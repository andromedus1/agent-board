# Ghostty 1.3 release notes

## Summary

Ghostty 1.3 added the macOS facilities that make targeted Agent Board
integration practical without tmux: AppleScript, targeted focus, and direct tab
title editing.

## Key passages

1. Ghostty 1.3 added double-click inline tab-title editing on macOS. (macOS
   changelog; line 318.)
2. Ghostty 1.3 added an app intent to focus a specific terminal through Apple
   Shortcuts. (macOS changelog; line 322.)
