## Summary

Apple Platform Support page on installing software updates on Mac. Describes Automatic Updates, overnight installation and Background Security Improvements.

## Key passages

- [1] "Automatic updates: Users choose Apple menu > System Settings, click General in the sidebar, click Software Update, then click Automatic Updates to turn on automatic installation. Updates can install overnight while the Mac is connected to power, Wi-Fi or Ethernet, and asleep."
- [2] Background Security Improvements: "They apply automatically by default and may require a Mac restart."

## Structural notes

- Does not state whether an automatic update restarts a FileVault-enabled Mac into the pre-boot unlock screen.
